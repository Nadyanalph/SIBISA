# SIBISA
### Sistem Informasi Bank Sampah

SIBISA merupakan aplikasi berbasis desktop yang dikembangkan untuk membantu pengelolaan bank sampah secara digital. Aplikasi ini menyediakan fitur pengelolaan data nasabah, jenis sampah, transaksi penyetoran, saldo tabungan, dan riwayat transaksi.

Proyek ini dibuat sebagai bagian dari tugas **Proyek Mandiri mata kuliah Pemrograman Berorientasi Objek II (PBO II)**.

## Teknologi
- Java 17
- Java Swing
- MySQL
- JDBC
- NetBeans IDE
